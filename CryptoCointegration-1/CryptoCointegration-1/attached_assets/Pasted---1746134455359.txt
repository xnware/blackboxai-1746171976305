# Промпт для описания проекта: Анализ коинтеграции и парный трейдинг криптовалют

## 📌 Цели проекта
1. **Автоматизация выявления коинтегрированных пар** криптовалют для поиска статистических арбитражных возможностей.
2. **Расчет ключевых метрик**:
   - Спред между активами.
   - Z-показатель и волатильность.
   - Результаты теста Дики-Фуллера (ADF) и Йохансена.
3. **Обеспечение высокой производительности** за счет:
   - Параллельной обработки данных.
   - Оптимизированных SQL-запросов.
   - Распределенных вычислений с использованием Modin.
4. **Интеграция с биржевыми API** (например, Gate.io) для сбора данных в реальном времени.
5. **Визуализация результатов** для упрощения принятия торговых решений.

## 🛠 Технологический стек
- **Язык программирования**: Python 3.9+.
- **Обработка данных**:
  - `Modin` (с бэкендом Ray/Dask) для работы с большими датасетами.
  - `pandas`, `NumPy` для векторных операций.
  - `statsmodels` для статистического анализа.
- **Базы данных**:
  - PostgreSQL для хранения исторических данных.
  - SQLAlchemy для ORM-взаимодействия.
- **Асинхронность**:
  - `aiohttp` для HTTP-запросов.
  - `asyncio` для управления параллельными задачами.
- **Дополнительные инструменты**:
  - `scikit-learn` для кластеризации символов.
  - `logging` и `ELK` (опционально) для мониторинга.
  - Docker для контейнеризации.

## 🏗 Архитектура системы
### Основные модули:
1. **Data Collector**:
   - Асинхронный сбор данных с бирж.
   - Парсинг свечей (OHLCV), объемов, стакана цен.
   - Сохранение сырых данных в PostgreSQL.

2. **Data Processor**:
   - Расчет спреда между парами активов.
   - Проверка стационарности временных рядов (ADF-тест).
   - Кластеризация активов по волатильности и корреляции.

3. **Cointegration Analyzer**:
   - Тестирование пар на коинтеграцию.
   - Формирование торговых сигналов при отклонении спреда от среднего.
   - Обновление результатов в отдельной таблице БД.

4. **Result Visualizer** (опционально):
   - Генерация графиков через Plotly.
   - Экспорт отчетов в формате PDF/CSV.

5. **Main Orchestrator**:
   - Управление расписанием задач.
   - Балансировка нагрузки между модулями.

## 🔍 Особенности реализации
- **Распределенные вычисления**:
  - Использование Modin для параллельной обработки DataFrame.
  - Партиционирование SQL-запросов по временным интервалам.
- **Асинхронность**:
  - Конкурентный сбор данных с 10+ бирж одновременно.
  - Обработка до 1000 пар активов в минуту.
- **Безопасность**:
  - Шифрование API-ключей через переменные окружения.
  - Защита от SQL-инъекций через параметризованные запросы.
- **Оптимизация**:
  - Кеширование частых запросов к БД.
  - Автоматическое создание индексов для ускорения аналитики.

## 🚀 Преимущества и инновации
- **Масштабируемость**:
  - Поддержка горизонтального масштабирования за счет Docker Swarm/Kubernetes.
  - Возможность обработки 1M+ данных в час.
- **Гибкость**:
  - Легкая интеграция новых бирж через модульную архитектуру.
  - Настройка параметров через `.env`-файл.
- **Точность**:
  - Комбинирование методов Энгла-Грейнджера и Йохансена.
  - Адаптивная калибровка параметров под рыночные условия.
